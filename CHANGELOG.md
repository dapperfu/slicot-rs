## [0.4.20] - 2025-03-16

### Added

- Initial production-oriented release.
- This crate is intended as a **drop-in replacement for SLICOT** in the Rust ecosystem (same routine names and semantics where implemented; pure Rust, nalgebra-based, no FFI).
- LICENSE (BSD-3-Clause), CHANGELOG, RELEASES, runnable examples, and CI (GitHub Actions).
- Explicit package `exclude` for plans/, tools/, SLICOT-Reference/, fuzz/, .github/.
- MSRV 1.70, crates.io keywords and categories.
